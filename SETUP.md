# Setup

1. Put `README.md` in your `fahimnow/fahimnow` profile repository.
2. Keep `assets/header.svg` beside it.
3. Keep `.github/workflows/snake.yml` in the exact location shown.
4. Replace the LinkedIn, portfolio, email and project URL placeholders.
5. Commit and push.
6. Open **Actions → Generate Contribution Snake → Run workflow** once.
7. The scheduled workflow will update the contribution snake automatically.

The README intentionally avoids invented project URLs and personal contact details.
